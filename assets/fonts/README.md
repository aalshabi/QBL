# Tajawal

الخط المستخدم في صورة المشاركة (Open Graph). نُسخ إلى المستودع عمداً بدل جلبه
وقت التنفيذ: توليد الصورة يجري داخل دالة على الحافة، وجلب خط من شبكة خارجية في
تلك اللحظة يعني أن فشل الشبكة يُنتج صورة بلا نص عربي — أو لا يُنتج صورة أصلاً.

- المصدر: Google Fonts (`fonts.gstatic.com`)، النسخة v12
- الترخيص: SIL Open Font License 1.1 — يسمح بإعادة التوزيع والتضمين
- الملفان بصيغة TTF لأن مولّد الصور (satori) لا يقرأ WOFF2

`next/font` يتكفل بخطوط الموقع نفسه؛ هذان الملفان لصورة المشاركة وحدها.
