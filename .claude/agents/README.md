# وكلاء منصة QBL.SA

مجموعة وكلاء متخصصين لتطوير موقع ومنصة **قدّام بابك (QBL)**. كل ملف `.md` في هذا المجلد وكيل مستقل بسياقه وصلاحياته، يستدعيه Claude Code تلقائياً حسب الطلب، أو تستدعيه أنت بالاسم.

## الاستخدام

**طلب واسع أو تقرير مهام سابقة** → وجّهه إلى `qbl-executive`:

```
استخدم qbl-executive: هذا تقرير من جلسة سابقة … عالجه بنداً بنداً حتى الإغلاق.
```

التنفيذي يفكّك التقرير، يتحقق من كل بند في الكود (التقرير مُدخل لا حقيقة)، يوزّع ما يحتاج عمقاً على المختصين، ويغلق كل بند بإصلاح ودليل، ثم يسلّم جدولاً بحالة كل بند.

**طلب أحادي واضح** → نادِ المختص مباشرة: `استخدم qbl-seo: أضف sitemap و robots`.

## الطاقم

| الوكيل | التخصص | يُستدعى لـ |
|---|---|---|
| `qbl-executive` | القيادة والتنفيذ الكامل | طلب واسع، تقرير مهام، «طوّر الموقع»، «وش ينقص» |
| `qbl-frontend` | Next.js 16 · React 19 · Tailwind 4 · RTL | صفحات، مكونات، تجاوب، حالات تحميل وخطأ |
| `qbl-backend` | مسارات API · Prisma 7 · منطق الدومين | endpoints، هجرات، تحقق مدخلات، صلاحيات خادمية |
| `qbl-integrations` | LogesTechs · Google Maps · تيليمتري · SMS/WhatsApp | ويبهوك، فحص اتصال، محوّلات المزوّدين |
| `qbl-security` | الأمن والخصوصية | مراجعة قبل النشر، توكنات، OTP، أسرار، ترويسات |
| `qbl-seo` | SEO تقني وبحث عربي | Metadata، sitemap، robots، JSON-LD، ar/en |
| `qbl-performance` | Core Web Vitals وحجم الحزمة | بطء، CLS، سكربتات ثقيلة، حدود العميل |
| `qbl-content` | المحتوى العربي وبوابة الادعاءات | كتابة ومراجعة أي نص يراه العميل |
| `qbl-brand-ux` | الهوية البصرية والتجربة والوصولية | اتساق بصري، تدفقات، WCAG AA |
| `qbl-qa` | الاختبارات والانحدار | `lint` / `test` / `build`، اختبارات جديدة |
| `qbl-devops` | البيئة والنشر على Vercel | متغيرات، cron، ترويسات، قائمة ما قبل الإطلاق |

## قواعد تسري على الجميع

1. **الإصلاح حتى النهاية.** البند يُغلق بتعديل في الكود ودليل، لا باقتراح ولا بخطة.
2. **التحقق قبل التصديق.** أي بند في تقرير وارد يُفحص في الكود أولاً؛ الإيجابيات الكاذبة تُرد بدليل.
3. **بوابة الادعاءات.** أي نص يراه طرف خارجي يمر على `qbl-content`. ممنوع دائماً: ضمان حرارة · عدد أسطول أو سائقين · أسماء أو عدد عملاء · نسب نجاح · اعتمادات وتراخيص · شراكات · صفات تفضيل.
4. **بوابة السعر.** تعرفة Beauty Shield غير معتمدة ولا تُنشر. المعتمد فقط: مبرّد 22 ريالاً · جاف 18 ريالاً · وزن زائد 1 ريال/كجم بعد 15 · COD‏ 1% نقاط بيع أو 2 ريال نقداً بحد 3,000 ريال.
5. **بوابة المؤسس.** توقّف قبل: نشر إنتاجي · تغيير أسعار أو وعود تعاقدية · هجرة مدمّرة · مفاتيح إنتاج · أي إجراء لا رجعة فيه.
6. **الخصوصية.** لا بيانات عميل في سجلات أو استجابات عامة أو لدى طرف ثالث لا يحتاجها.
7. **بوابة التسليم التقني.** `npm run lint` و `npm run test` و `npm run build` تمر قبل أي تسليم، بلا إضعاف فحص أو تعطيل اختبار.
