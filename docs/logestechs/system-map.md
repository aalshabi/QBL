# خريطة نظام LogesTechs — سجل الفحص

آخر تحديث: 2026-08-16
الحالة: بدأ الفحص الداخلي بجلسة مصادقة وبوضع القراءة فقط؛ 94 رابط تنقل و12 شاشة تشغيل/إعداد رئيسية موثقة حتى الآن.

## نقطة الوصول

- الرابط المطلوب: `https://admin-pro.logestechs.com/qbl%20logistics/home/dashboard`.
- الجلسة الحالية: مصادقة وفعالة داخل حساب QBL.
- لم تُقرأ بيانات اعتماد ولم تُنفذ أي عملية Write.
- لم تُسجل بيانات صفوف العملاء أو الشحنات أو URLs/Payloads الخاصة بالتكامل.

## قالب سجل الشاشة

لكل شاشة تُفحص لاحقًا يُسجل:

- Screen وMenu path.
- Purpose وEntities.
- Tabs وFilters وSearch.
- Buttons وDropdowns وBulk Actions.
- Tables وColumns وStatuses وPagination.
- Forms وValidation وError messages.
- Workflow transitions والصلاحيات الظاهرة.
- Import/Export/Print.
- Read-only Network metadata عند توفرها.
- Evidence IDs وConfidence.

## حدود الفحص

لا ضغط على أي إجراء قد يغيّر شحنة، سائقًا، مركبة، حالة، إعدادًا، رسالة، فاتورة، تسوية، مستخدمًا أو تكاملًا. فتح View أو Modal مسموح فقط بعد التأكد أنه لا ينفذ حفظًا مباشرًا.
